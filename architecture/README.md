# Architecture

This folder is intended to hold the project architecture diagrams and design documentation.

## Current purpose

The repository includes this folder as a place for:

- system architecture diagrams
- cloud architecture discussion
- flow diagrams for the smart-grid AI system

## What the project actually implements

The actual implementation in the codebase is:

- Python-based data preprocessing and training
- KNN graph creation for the GNN
- Flask backend for inference
- HTML/CSS/JavaScript frontend for user interaction

The architecture folder does not currently contain the actual diagram files inside the repository, so it should be treated as a documentation placeholder for architecture work rather than a complete deployed architecture package.
