## Problem Statement

Modern smart grids generate a large amount of data from sensors and smart devices. Traditional methods cannot accurately predict equipment failures because they do not consider the relationships between connected devices. This project uses Graph Neural Networks (GNNs) and AWS Cloud Services to predict smart grid reliability and improve system performance.

## Objectives

- Develop an AI-based reliability prediction system.
- Use Graph Neural Networks for prediction.
- Deploy the system using AWS Cloud.
- Provide real-time monitoring.
- Improve prediction accuracy.
- Reduce maintenance cost.
